# Run River UI / UX direction

## Subject and purpose

일상 러닝·걷기를 기록하는 iPhone 웹앱. 밖에서 한 손으로 목표를 고르고, 달리는 동안 현재 기록을 빠르게 읽고, 완료 후 기록을 돌아보는 흐름을 우선한다.

## Design tokens

- 안개 `#F1F5F4`: 지도 대체 화면·앱 바탕
- 종이 `#FCFDFC`: 정보와 조작 면
- 깊은 강 `#123D46`: 브랜드와 주요 텍스트
- 흐르는 물 `#216D74`: 시작·선택·경로
- 이끼 `#627C50`: 걷기 상태
- 경고 `#B94747`: 오류·종료 등 주의가 필요한 동작

한글과 안내 문구는 Pretendard 및 iOS 시스템 글꼴, 기록 숫자는 시스템 디스플레이 글꼴과 tabular numbers를 사용한다. 외부 글꼴이 없어도 읽을 수 있게 한다. 12/14/16/22/30px의 글자 크기와, 운동 중 숫자의 별도 크기 체계를 사용한다.

## Layout

홈은 지도를 배경으로 유지하고 아래 조작 면에서 목표를 고른다. 주요 기록 숫자는 왼쪽 정렬한다. 공통 화면 헤더와 하단 탐색으로 운동·기기 기록·통계·설정을 오간다. 실제 러닝 중에는 탐색을 숨겨 실수로 이탈하지 않게 한다.

```text
홈                  러닝                 기록
브랜드 / 지도 도구     상태 / 음성           화면 제목
                    거리                 날짜 / 거리 / 시간
지도 / 위치           시간 / 페이스         경로와 저장 상태
오늘의 운동 설정       이동 궤적              기록 목록
목표 / 활동 / 시작     일시정지 / 종료        공통 탐색
```

## Review before build

일반적인 운동 앱의 검정·형광색 조합 대신 강변의 청록·안개색을 선택했다. 모든 섹션을 같은 카드로 만들지 않고, 조작은 분명한 면으로, 보조 정보는 구분선과 여백으로 구별한다. 브랜드의 기억점은 한 줄로 이어지는 강 모양 SVG와 정돈된 기록 숫자에 둔다. 장식용 그라데이션과 반복적인 등장 애니메이션은 추가하지 않는다.

## UX and verification

기존 운동·오프라인·복구 동작은 유지한다. 상태 안내는 필요한 맥락에 배치하고 동작 이름을 일관되게 유지한다. 44px 이상의 주요 조작 영역, 포커스 표시, 선택 상태, reduced motion, 작은 iPhone 화면과 다크 모드를 확인한다. 기존 Chromium/WebKit 오프라인 테스트와 화면별 스크린샷을 검증에 사용한다.

## Build critique and changes

- 홈 패널이 헤더를 덮던 구성을 조정하고 시작 버튼을 스크롤 영역 밖에 고정했다. 활동 종류를 거리·시간 목표 옆으로 옮겨 조작 밀도를 줄였다.
- 완료 화면의 긴 저장 안내는 브랜드 행과 분리했다. 게스트에게 대기 0건의 업로드 버튼을 보여주지 않는다.
- 숫자·배경·보조 텍스트의 명도 대비를 확인하고 작은 텍스트를 더 진하게 조정했다. 색상만으로 선택을 전달하지 않게 aria-pressed / aria-current를 사용한다.
- 오프라인에서 열 수 없는 탐색 항목은 상태를 알리고 현재 화면을 유지한다.
- 첫 서비스 워커 설치 시 불필요한 새로고침, Windows 터치 API 감지로 인한 데스크톱 오판별, 페이스의 60초 반올림 표시, 완료 경로의 시작점으로 되돌아가는 표시를 함께 수정했다.
- Chromium/WebKit에서 홈·러닝·결과·빈 기록·기록 목록·통계·설정·로그인·데스크톱과 다크/320px 화면을 촬영한다. 실제 iPhone OS 동작을 검증했다고 간주하지 않는다.
