# 하이킹과 GPX 코스

홈의 **하이킹 시작** 또는 `/hiking`에서 시작한다. 먼저 `/maps`에서 산행 지역 지도를 저장하고 선택한다. GPX 코스는 선택 사항이며 코스 없이 자유롭게 기록할 수도 있다. 시작할 때 정확도 40m 이내의 현재 GPS 위치를 확인한다.

## 동작

- 하이킹은 `hiking` 운동 유형으로 저장한다. 러닝·걷기 기록과 구분하고 기기 기록에서 필터링할 수 있다.
- Android는 네이티브 foreground 위치 서비스와 SQLite를 사용한다. 웹은 기존 위치 API와 기기 복구 기능을 유지하므로 화면 잠금 중 연속 기록을 보장하지 않는다.
- 하이킹은 자동 일시정지와 속도를 올리라는 음성 코칭을 사용하지 않는다. 쉬는 동안에는 직접 일시정지한다. 기록 시간에는 일시정지하지 않은 휴식도 포함된다.
- GPX는 5MB 이하, 2~10,000개 좌표의 단일 연속 트랙 또는 경로를 지원한다. 여러 트랙·끊어진 세그먼트는 임의로 연결하지 않고 가져오기를 거절한다. 잘못된 파일이 기존 코스를 덮어쓰지 않는다.
- Android 운동 화면은 위치가 최신이고 코스에서 80m 또는 GPS 정확도의 2배 이상 벗어난 상태가 15초 지속되면 화면에 안내한다. 코스와의 거리는 샘플 지점이 아니라 선분까지 계산한다. 백그라운드 음성·이탈 알림이나 자동 경로 재탐색은 포함하지 않는다.
- 결과에서 GPS 이동 경로를 GPX로 내보낼 수 있다. 고도·시간과 GPS 공백의 세그먼트 구분을 보존한다. 일시정지·긴 GPS 공백을 지도에 하나의 직선으로 연결하지 않는다.
- Android GPX 내보내기는 네이티브 문서 저장 창에서 사용자가 선택한 위치에 쓴다. 웹은 브라우저 다운로드를 사용한다. Android 앱에서 Blob 다운로드 지원에 의존하지 않는다.
- 큰 코스 설정은 SQLite의 별도 테이블에 한 번 저장한다. 위치 체크포인트는 시간·거리 등 변경되는 정보만 기록한다. 이전 SQLite v1 기록은 v2로 이전하며 설정과 좌표를 유지한다.

## 서버 상태와 동기화

2026-11-14 연결된 Run-River Supabase 프로젝트 상태가 `INACTIVE`임을 확인했다. 프로젝트를 복원하거나 운영 DB를 변경하지 않았다. 하이킹은 기본적으로 기기에 보존하고 서버 업로드 대기열에 새로 넣지 않는다. 결과와 기기 기록 화면에도 이를 표시한다. 기존 러닝·걷기 업로드 동작은 유지한다.

`supabase/migrations/20261114054130_add_hiking_activity.sql`은 기존 `running_records`의 운동 종류 CHECK 조건에 hiking을 추가한다. 테이블·기존 기록·RLS·소유자 정책은 변경하지 않는다. 기존 테이블이 존재하는 데이터베이스용 증분 변경이며 새 프로젝트는 먼저 기본 스키마를 준비해야 한다. CLI의 `migration new`로 생성했으며 운영 DB에는 적용하지 않았다.

서버 동기화를 켜려면 다음을 먼저 완료해야 한다.

1. 올바른 기존 프로젝트의 복원 상태와 DB 접근을 확인한다.
2. 실제 제약 이름과 RLS를 확인하고 준비한 migration을 적용한다.
3. 소유 계정으로 하이킹 저장·읽기와 다른 계정 접근 차단을 확인한다.
4. 그 후에만 `NEXT_PUBLIC_HIKING_SYNC=1`로 웹과 APK를 다시 빌드한다.

기존 기기 하이킹 기록은 플래그를 켠 빌드에서 결과 화면을 열면 원래 소유 계정으로 업로드할 수 있다. 활성화 전에는 클라우드 통계에 하이킹이 포함되지 않는다. `hiking-schema` CI는 일회용 PostgreSQL 17에서 기존 기록 보존·hiking 허용·잘못된 종류 거부·RLS와 소유 정책 보존을 검사한다. 운영 환경 검증을 대신하지 않는다.

## 남은 실제 기기 검사

Android 설치 후 데이터 차단·화면 잠금·앱 전환 중 좌표 저장, 재개·종료, 앱 재시작 복구, 지도 다운로드·파일 선택·삭제, GPX 코스 표시, 배터리 소비를 확인해야 한다. 실기기 결과 없이 장시간 산행 검증 완료로 간주하지 않는다. 브라우저·네이티브 모의 테스트와 Android 컴파일은 별도 증거다.
